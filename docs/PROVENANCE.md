# Provenance and asset notes

Nocodile's shadow-clone effect is based on Nasha Wanich's public `naruto-shadow-clone-jutsu` project:

https://github.com/nasha-wanich/naruto-shadow-clone-jutsu

The smoke frames and `state-1.png` / `state-2.png` artwork in `public/assets/` were copied from that project during development. The clone positions, scales, delays, and smoke timing also intentionally follow the original implementation.

The reviewed upstream snapshot did not contain an explicit license. This repository therefore does not assert a license grant for those upstream assets. Confirm redistribution rights before publishing or relicensing them.

The browser-local training/persistence workflow, shared-camera architecture, feature representation, recovery behavior, tests, and current UI are later work built around that reference effect.
